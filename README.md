# devmyna.github.io

公式ホームページ（ペライチ / 1ページ完結型サイト）

## 構成
- **プロフィール (Profile)**: 顔写真、自己紹介、基本情報
- **略歴 (Biography)**: タイムライン形式の経歴一覧
- **お知らせ (News)**: サムネイル画像・タイトル付きの最新情報（画像・タイトル双方にリンク対応）
- **お問い合わせ (Contact)**: メール・電話などの連絡先案内

## 特徴
- **シニア・全世代対応のユニバーサルデザイン**:
  - 大きめで視認性の高いフォント（Noto Sans JP）と十分な行間・コントラスト
  - 画面上部の「文字の大きさ：標準 / 大」切り替えボタン（状態は保存されます）
  - タップしやすい大きなボタンと直感的なナビゲーション
- **完全レスポンシブ対応**: スマートフォン、タブレット、パソコンに最適化
- **純粋なHTML/CSS/JS**: フレームワーク不要で高速・軽量、GitHub Pagesでそのまま公開可能

## ファイル構成
```
.
├── index.html       # メインHTML
├── style.css        # スタイルシート（レスポンシブ・文字拡大対応）
├── script.js        # 文字サイズ変更、トップへ戻るボタン等
└── images/          # 画像フォルダ
    ├── profile.jpg  # プロフィール写真
    ├── news1.jpg    # お知らせ1 サムネイル
    ├── news2.jpg    # お知らせ2 サムネイル
    └── news3.jpg    # お知らせ3 サムネイル
```
